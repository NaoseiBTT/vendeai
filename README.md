# VendeAí 🛒

O **VendeAí** é uma aplicação de marketplace desenvolvida durante as aulas de desenvolvimento de sistemas.

A proposta é permitir que usuários possam **cadastrar e visualizar anúncios de produtos**, trabalhando conceitos de desenvolvimento backend e arquitetura de aplicações.

## 🚀 Tecnologias

### Backend

* Node.js
* NestJS
* TypeScript
* Class Validator
* Vitest

### Futuramente

* Frontend
* Banco de dados
* Autenticação
* Docker
* CI/CD

## 📁 Estrutura do projeto

```text
vendeai/
├── backend/
└── frontend/
```

Atualmente, o desenvolvimento está concentrado no **backend**.

## 🎯 Objetivo

O projeto está sendo desenvolvido de forma incremental, aplicando conceitos como:

* DTOs
* Validação de dados
* Arquitetura em camadas
* Testes automatizados
* Princípios SOLID
* Boas práticas de desenvolvimento

> Projeto desenvolvido para fins educacionais e de prática em desenvolvimento de software.
